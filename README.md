# Aluminium OS (Debian Edition)

Сборка Debian GNU/Linux с полноценным визуальным окружением и управлением, идентичным **Aluminium OS / Googlebook OS (Android Desktop)**.

---

## Особенности интерфейса и управления

### 1. Оконный менеджер и элементы управления (Window Controls)
* **Расположение кнопок**: справа в заголовке окна (`:minimize,maximize,close`).
* **Стиль Material 3**:
  * Круглые кнопки управления (диаметр 28px) с плавными круговыми эффектами наведения (ripple effect).
  * Кнопка закрытия подсвечивается акцентным мягким красным цветом (`#ea4335` / `#f28b82`).
  * Кнопки свернуть (`—`) и развернуть (`□`) выполнены в строгом геометрическом стиле Google Material.
* **Закругление углов окон**: радиус 16px в нормальном режиме, 0px в полноэкранном режиме.
* **Тени и глубина**: мягкая глубокая тень Elevation 3 (`0 10px 30px rgba(0, 0, 0, 0.55)`).
* **Сетка и тайлинг (Snapping)**:
  * `Super + Left`: фиксация окна на левой половине экрана (Split-Screen).
  * `Super + Right`: фиксация окна на правой половине экрана (Split-Screen).
  * `Super + Up`: развернуть на весь экран.
  * `Super + Down`: восстановить исходный размер / свернуть.
  * `Super + H`: скрыть окно.
  * `Alt + F4` / `Super + Q`: закрыть окно.
  * Перетаскивание к верхнему краю разворачивает окно, перетаскивание к боковым краям делит экран пополам.

### 2. Нижняя плавающая полка (Floating Shelf / Dock)
* Плавающая капсула (pill) с закруглёнными углами (радиус 28px) по центру внизу экрана.
* Полупрозрачный фон с эффектом матового стекла (`rgba(24, 26, 31, 0.85)`).
* Кнопка запуска меню приложений слева на полке в виде официального логотипа **Google "G"**.
* Индикаторы запущенных приложений: светящиеся аккуратные точки под иконками.

### 3. Верхняя строка состояния (Status Bar)
* Ультратонкая полупрозрачная панель вверху экрана.
* Слева: дата и время (`2:07 Fri, 11 Oct`).
* Справа: иконки состояния (Wi-Fi, Bluetooth, звук, заряд батареи с процентами) и шторка быстрых настроек (Quick Settings).

### 4. Тема и обои
* Фирменные обои Aluminium OS: градиентная волна-лента на глубоком полуночно-синем фоне.
* Цветовая палитра Material 3 Dark (фон `#131518`, контейнеры `#1c1e22`, синий акцент `#a8c7fa`).
* Шрифты: Roboto / Google Sans.
* Иконки: круглые Material Icons (Papirus-Dark).

## Сборка ISO-образа

### Требования
* ОС: Debian 12 (Bookworm) / Ubuntu 22.04+
* Пакеты: `live-build`, `debootstrap`, `squashfs-tools`, `xorriso`

### Запуск сборки
```bash
cd aluminium-debian
sudo ./build-iso.sh
```

Готовый гибридный ISO-образ появится в папке `aluminium-debian/dist/aluminium-os-debian-amd64.iso`.
Его можно записать на флешку (через `dd`, Rufus или BalenaEtcher) и загрузиться на любом ноутбуке или ПК.

### Тестирование в QEMU
```bash
./test-qemu.sh
```

### Установка на накопитель
В Live-сессии на рабочем столе и в полке доступен графический установщик **Calamares** («Install Aluminium OS»), позволяющий установить систему на внутренний SSD / NVMe или рядом со второй ОС (Dual-Boot).
